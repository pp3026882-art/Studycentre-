1. Number Systems क्या है?

संख्याओं को उनके गुणों के आधार पर अलग-अलग समूहों में बाँटा जाता है। इन्हें Number Systems कहते हैं।

English: A number system classifies numbers into different groups according to their properties.

Natural Numbers (प्राकृतिक संख्याएँ)

गिनती की संख्याएँ Natural Numbers कहलाती हैं।

N = {1, 2, 3, 4, 5, ...}

Whole Numbers (पूर्ण संख्याएँ)

प्राकृतिक संख्याओं में शून्य जोड़ने पर Whole Numbers मिलते हैं।

W = {0, 1, 2, 3, 4, ...}

Integers (पूर्णांक)

ऋणात्मक संख्याएँ, शून्य और धनात्मक संख्याएँ Integers कहलाती हैं।

Z = {..., -3, -2, -1, 0, 1, 2, 3, ...}

Rational Numbers (परिमेय संख्याएँ)

वे संख्याएँ जिन्हें p/q के रूप में लिखा जा सकता है, जहाँ p और q पूर्णांक हों तथा q ≠ 0 हो।

उदाहरण: 1/2, 3/4, -2/5, 5 = 5/1

Irrational Numbers (अपरिमेय संख्याएँ)

वे वास्तविक संख्याएँ जिन्हें p/q के रूप में नहीं लिखा जा सकता, Irrational Numbers कहलाती हैं।

उदाहरण: √2, √3, √5, π

Real Numbers (वास्तविक संख्याएँ)

परिमेय और अपरिमेय संख्याएँ मिलकर Real Numbers बनाती हैं।

N ⊂ W ⊂ Z ⊂ Q ⊂ R

2. Decimal Expansion (दशमलव प्रसार)

Terminating Decimal (सांत दशमलव)

जिस दशमलव का अंत हो जाता है।

1/2 = 0.5
1/4 = 0.25
1/8 = 0.125

Non-terminating Recurring Decimal (असांत आवर्ती दशमलव)

जिसमें कोई अंक या अंकों का समूह बार-बार दोहराता है।

1/3 = 0.333...
2/11 = 0.181818...

Irrational Decimal (अपरिमेय दशमलव)

इसका दशमलव प्रसार असांत और अनावर्ती होता है।

√2 = 1.4142135...

3. Laws of Exponents (घातांक के नियम)

1. aᵐ × aⁿ = aᵐ⁺ⁿ
2. aᵐ ÷ aⁿ = aᵐ⁻ⁿ, जहाँ a ≠ 0
3. (aᵐ)ⁿ = aᵐⁿ
4. a⁰ = 1, जहाँ a ≠ 0
5. a⁻ᵐ = 1/aᵐ, जहाँ a ≠ 0
6. aᵐ/ⁿ = ⁿ√(aᵐ), जहाँ यह परिभाषित हो

4. Ten Solved Examples (10 हल किए हुए उदाहरण)

Example 1: 7 किस प्रकार की संख्या है?

7 एक Natural Number है। यह Whole Number, Integer, Rational और Real Number भी है।

7 ∈ N, W, Z, Q, R
उत्तर: प्राकृतिक, पूर्ण, पूर्णांक, परिमेय और वास्तविक संख्या।

Example 2: क्या 3/5 परिमेय संख्या है?

परिमेय संख्या p/q के रूप में होती है, जहाँ p और q पूर्णांक तथा q ≠ 0 हो।

3/5 में p = 3 और q = 5
उत्तर: हाँ, 3/5 परिमेय संख्या है।

Example 3: √49 का मान ज्ञात करो।

√49 = √(7 × 7) = 7
उत्तर: 7

Example 4: √2 परिमेय है या अपरिमेय?

√2 को दो पूर्णांकों के अनुपात में ठीक-ठीक नहीं लिखा जा सकता। इसका दशमलव प्रसार असांत और अनावर्ती है।

उत्तर: अपरिमेय संख्या।

Example 5: 1/8 का दशमलव रूप लिखो।

1 ÷ 8 = 0.125
उत्तर: 0.125, एक सांत दशमलव।

Example 6: 1/3 का दशमलव रूप लिखो।

1 ÷ 3 = 0.3333...
उत्तर: 0.333..., एक असांत आवर्ती दशमलव।

Example 7: 2³ × 2⁴ सरल करो।

नियम: aᵐ × aⁿ = aᵐ⁺ⁿ

2³ × 2⁴ = 2⁷ = 128
उत्तर: 128

Example 8: 5⁶ ÷ 5² सरल करो।

नियम: aᵐ ÷ aⁿ = aᵐ⁻ⁿ

5⁶ ÷ 5² = 5⁴ = 625
उत्तर: 625

Example 9: (3²)³ सरल करो।

नियम: (aᵐ)ⁿ = aᵐⁿ

(3²)³ = 3⁶ = 729
उत्तर: 729

Example 10: 2⁻³ का मान ज्ञात करो।

नियम: a⁻ᵐ = 1/aᵐ

2⁻³ = 1/2³ = 1/8
उत्तर: 1/8

  2. 9
  3. अपरिमेय
  4. 0.375
  5. 3⁵ = 243
  6. 2⁴ = 16

  8. परिमेय संख्या

  10. 2⁶ = 64

6. Quick Revision (झटपट दोहराएँ)

  • Natural Numbers: 1, 2, 3, ...
  • Whole Numbers: 0, 1, 2, 3, ...
  • Integers: ..., -2, -1, 0, 1, 2, ...
  • Rational Number: p/q, जहाँ q ≠ 0
  • Irrational Number: असांत और अनावर्ती दशमलव
  • Real Numbers में Rational और Irrational दोनों आते हैं।
