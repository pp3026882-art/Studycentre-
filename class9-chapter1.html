Chapter 1: The Use of Coordinates

अध्याय 1: निर्देशांक का उपयोग

Learning Objective / सीखने का उद्देश्य:

To understand coordinates, the coordinate plane, ordered pairs and how to locate points.

निर्देशांकों, निर्देशांक तल, क्रमित युग्म तथा बिंदुओं की स्थिति को समझना।

1. What are Coordinates? | निर्देशांक क्या हैं?

English: Coordinates are numbers used to describe the exact position of a point on a plane.

हिंदी: निर्देशांक वे संख्याएँ हैं जिनकी सहायता से समतल पर किसी बिंदु की सही स्थिति बताई जाती है।

Example / उदाहरण:
The point (3, 2) means move 3 units right and 2 units up from the origin.
बिंदु (3, 2) का अर्थ है मूल बिंदु से 3 इकाई दाईं ओर और 2 इकाई ऊपर जाना।

2. Coordinate Plane | निर्देशांक तल

The coordinate plane has two number lines that meet at right angles.

निर्देशांक तल में दो संख्या रेखाएँ एक-दूसरे को समकोण पर काटती हैं।

  • X-axis (क्षैतिज अक्ष): The horizontal number line / आड़ी संख्या रेखा।
  • Y-axis (ऊर्ध्वाधर अक्ष): The vertical number line / खड़ी संख्या रेखा।
  • Origin (मूल बिंदु): The intersection of both axes, (0, 0) / दोनों अक्षों का मिलन बिंदु।

ऊपर के ग्राफ में किसी बिंदु का स्थान देखने के लिए नीचे x और y के मान भरें।




3. Ordered Pair | क्रमित युग्म

A point is written as (x, y). The first number represents the horizontal position, and the second number represents the vertical position.

किसी बिंदु को (x, y) के रूप में लिखते हैं। पहली संख्या क्षैतिज स्थिति और दूसरी संख्या ऊर्ध्वाधर स्थिति बताती है।

(x, y) = (horizontal position, vertical position)
Example 1: (4, 1)
Move 4 units right and 1 unit up.
4 इकाई दाईं ओर और 1 इकाई ऊपर जाएँ।
Example 2: (-2, 3)
Move 2 units left and 3 units up.
2 इकाई बाईं ओर और 3 इकाई ऊपर जाएँ।
Example 3: (2, -3)
Move 2 units right and 3 units down.
2 इकाई दाईं ओर और 3 इकाई नीचे जाएँ।

4. Four Quadrants | चार चतुर्थांश

The x-axis and y-axis divide the plane into four regions called quadrants.

x-अक्ष और y-अक्ष समतल को चार भागों में बाँटते हैं, जिन्हें चतुर्थांश कहते हैं।

  • First Quadrant (I): (+, +) — x positive, y positive.
  • Second Quadrant (II): (-, +) — x negative, y positive.
  • Third Quadrant (III): (-, -) — x negative, y negative.
  • Fourth Quadrant (IV): (+, -) — x positive, y negative.
I: (+,+)   II: (-,+)
III: (-,-)   IV: (+,-)

Note: A point on either axis does not lie in any quadrant.

ध्यान दें: अक्ष पर स्थित बिंदु किसी भी चतुर्थांश में नहीं होता।

5. Solved Examples | हल किए हुए उदाहरण

Example 1: Write the coordinates of a point 5 units right and 2 units up from the origin.
Solution: Right means positive x; up means positive y.
Answer: (5, 2)
Example 2: In which quadrant is (-3, 4)?
Solution: x is negative and y is positive.
Answer: Second quadrant / द्वितीय चतुर्थांश।
Example 3: In which quadrant is (-2, -5)?
Solution: Both coordinates are negative.
Answer: Third quadrant / तृतीय चतुर्थांश।
Example 4: What are the coordinates of the origin?
Answer: (0, 0)
Example 5: A point is 4 units left and 3 units down. Write its coordinates.
Answer: (-4, -3)
Example 6: In which quadrant is (6, -1)?
Answer: Fourth quadrant / चतुर्थ चतुर्थांश।
Example 7: Is (0, 4) in a quadrant?
Answer: No. It lies on the y-axis / यह y-अक्ष पर है।
Example 8: Which coordinate is written first in (x, y)?
Answer: The x-coordinate / x-निर्देशांक।

6. Practice Questions | अभ्यास प्रश्न

पहले प्रश्न स्वयं हल करें। फिर उत्तर देखने के लिए बटन दबाएँ।

Q1. What are the coordinates of the origin?

(0, 0)

Q2. In which quadrant is (3, 5)?

First quadrant / प्रथम चतुर्थांश।

Q3. In which quadrant is (-4, 2)?

Second quadrant / द्वितीय चतुर्थांश।

Q4. In which quadrant is (-2, -6)?

Third quadrant / तृतीय चतुर्थांश।

Q5. In which quadrant is (7, -3)?

Fourth quadrant / चतुर्थ चतुर्थांश।

Q6. Write the point 2 units left and 4 units up.

(-2, 4)

Q7. Does (0, -5) lie in a quadrant?

No, it lies on the y-axis / यह y-अक्ष पर है।

Q8. What does the first coordinate in (x, y) represent?

Horizontal position / क्षैतिज स्थिति।

Q9. Write coordinates for 3 units right and 2 units down.

(3, -2)

Q10. On which axis does (5, 0) lie?

X-axis / x-अक्ष।

7. Quick Revision | त्वरित दोहराव

  • Coordinates show the position of a point. / निर्देशांक बिंदु की स्थिति बताते हैं।
  • The origin is (0, 0). / मूल बिंदु (0, 0) है।
  • An ordered pair is written as (x, y). / क्रमित युग्म (x, y) होता है।
  • The x-coordinate is written first. / पहले x-निर्देशांक लिखा जाता है।
  • The y-coordinate is written second. / दूसरे स्थान पर y-निर्देशांक होता है।
  • There are four quadrants. / चार चतुर्थांश होते हैं।
  • Points on the axes are not in any quadrant. / अक्षों पर स्थित बिंदु किसी चतुर्थांश में नहीं होते।
