1. Introduction | परिचय

English: An algorithm is a finite sequence of clear, ordered steps used to solve a problem or complete a task.

हिंदी: किसी समस्या को हल करने या कार्य पूरा करने के लिए बनाए गए स्पष्ट और क्रमबद्ध सीमित चरणों को एल्गोरिदम कहते हैं।

Example: Making tea follows a sequence of steps, such as boiling water, adding tea leaves and serving the tea.

2. Characteristics of an Algorithm | एल्गोरिदम की विशेषताएँ

  • Input: It may accept input values. / इसमें इनपुट हो सकता है।
  • Output: It produces a result. / यह परिणाम देता है।
  • Clarity: Every step should be clear. / हर चरण स्पष्ट होना चाहिए।
  • Finiteness: It should finish after a finite number of steps. / यह सीमित चरणों में समाप्त होना चाहिए।
  • Effectiveness: Each step should be practical to perform. / प्रत्येक चरण किया जा सकने वाला हो।

3. Algorithm to Add Two Numbers | दो संख्याएँ जोड़ने का एल्गोरिदम

Step 1: Start
Step 2: Input A and B
Step 3: SUM = A + B
Step 4: Display SUM
Step 5: Stop
Example: A = 5, B = 7
SUM = 5 + 7 = 12

4. Algorithm to Find the Larger Number | बड़ी संख्या ज्ञात करना

Step 1: Start
Step 2: Input A and B
Step 3: If A > B, display A
Step 4: Else if B > A, display B
Step 5: Otherwise, display "Both are equal"
Step 6: Stop
Example: A = 12, B = 8
Output: 12 is larger.

5. Algorithm to Find an Even or Odd Number | सम या विषम

Step 1: Start
Step 2: Input N
Step 3: If N % 2 == 0, display "Even"
Step 4: Otherwise, display "Odd"
Step 5: Stop

हिंदी: यदि संख्या को 2 से भाग देने पर शेषफल 0 हो, तो वह सम है; अन्यथा विषम है।

N = 14 → Even / सम
N = 9 → Odd / विषम

6. Algorithm to Find the Area of a Rectangle | आयत का क्षेत्रफल

Step 1: Start
Step 2: Input length L and breadth B
Step 3: AREA = L × B
Step 4: Display AREA
Step 5: Stop
Area = Length × Breadth
क्षेत्रफल = लंबाई × चौड़ाई
L = 8, B = 4
Area = 8 × 4 = 32 square units

7. Algorithm to Find the Average | औसत निकालना

Step 1: Start
Step 2: Input A, B and C
Step 3: SUM = A + B + C
Step 4: AVG = SUM / 3
Step 5: Display AVG
Step 6: Stop
A = 10, B = 20, C = 30
Average = 60 ÷ 3 = 20

8. Algorithm and Flowchart | एल्गोरिदम और फ्लोचार्ट

एल्गोरिदम चरणों में लिखे निर्देश हैं। फ्लोचार्ट उन्हीं चरणों को चित्रात्मक प्रतीकों द्वारा दिखाता है।

  • Oval: Start / Stop
  • Parallelogram: Input / Output
  • Rectangle: Process / गणना
  • Diamond: Decision / निर्णय
  • Arrow: Flow direction / दिशा

9. Important Terms | महत्वपूर्ण शब्द

  • Input: दी गई जानकारी।
  • Output: प्राप्त परिणाम।
  • Process: जानकारी पर किया गया कार्य।
  • Condition: जाँचने वाला नियम।
  • Loop: किसी चरण को दोहराना।
  • Pseudocode: सरल भाषा में लिखे गए प्रोग्राम-जैसे चरण।

10. 15 Solved Examples | 15 हल किए गए उदाहरण

Example 1: Add 4 and 6.
4 + 6 = 10
Example 2: Subtract 3 from 10.
10 − 3 = 7
Example 3: Multiply 5 by 4.
5 × 4 = 20
Example 4: Divide 20 by 5.
20 ÷ 5 = 4
Example 5: Check whether 12 is even.
12 % 2 = 0, so it is Even.
Example 6: Check whether 7 is odd.
7 % 2 = 1, so it is Odd.
Example 7: Find the larger number: 9 and 14.
Answer: 14
Example 8: Find the area of a rectangle with length 6 and breadth 3.
Area = 6 × 3 = 18
Example 9: Find the perimeter of a square with side 5.
Perimeter = 4 × 5 = 20
Example 10: Find the average of 4, 8 and 12.
Average = 24 ÷ 3 = 8
Example 11: Find the square of 6.
6 × 6 = 36
Example 12: Find the cube of 3.
3 × 3 × 3 = 27
Example 13: Add three numbers: 2, 3 and 4.
Sum = 2 + 3 + 4 = 9
Example 14: A number is 18. Is it divisible by 3?
1 + 8 = 9, so yes, 18 is divisible by 3.
Example 15: Find the area of a square with side 7.
Area = 7 × 7 = 49 square units

  15. एल्गोरिदम में Stop चरण क्यों आवश्यक है?
  1. किसी समस्या को हल करने के लिए स्पष्ट और क्रमबद्ध सीमित चरण।
  2. स्पष्टता और सीमित चरणों में समाप्त होना।
  3. Start → Input 5, 8 → Sum = 5 + 8 → Display 13 → Stop.
  4. Start → Input 20, 7 → Difference = 20 − 7 → Display 13 → Stop.
  5. 16 सम है।
  6. 11 विषम है।
  7. 19 बड़ी संख्या है।

  9. Perimeter = 4 × 6 = 24 इकाई।
  10. Average = (5 + 10 + 15) ÷ 3 = 10.
  11. किसी प्रक्रिया को चित्रों और प्रतीकों से दिखाना।
  12. Diamond / हीरे का आकार।
  13. Input दिया गया डेटा है; output प्राप्त परिणाम है।
  14. Square = 7 × 7 = 49.
  15. यह एल्गोरिदम के समाप्त होने को दर्शाता है।

12. Quick Revision | त्वरित दोहराव

Algorithm = समस्या हल करने के क्रमबद्ध चरण
Rectangle Area = Length × Breadth
Square Perimeter = 4 × Side
Average = Sum ÷ Number of values
