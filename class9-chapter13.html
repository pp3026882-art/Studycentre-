Linear Equations in Two Variables

दो चरों में रैखिक समीकरण | Hindi + English

⌂ Home All Chapters ← Chapter 12 Chapter 14 →

1. Introduction | परिचय

English: A linear equation in two variables is an equation that can be written as ax + by + c = 0, where a, b and c are constants and a and b are not both zero.

हिंदी: दो चरों में रैखिक समीकरण वह समीकरण है जिसे ax + by + c = 0 के रूप में लिखा जा सकता है। यहाँ a, b और c अचर हैं तथा a और b दोनों एक साथ शून्य नहीं होते।

General form: ax + by + c = 0
Example: 2x + 3y = 12

यहाँ x और y चर हैं। किसी समीकरण के हल के लिए x और y के ऐसे मान चाहिए जो समीकरण को सत्य बनाएँ।

2. Important Concepts | महत्वपूर्ण बातें

  • Variables (चर): x और y जैसे अक्षर जिनके मान बदल सकते हैं।
  • Solution (हल): x और y का ऐसा क्रमित युग्म (x, y), जो समीकरण को सत्य करे।
  • Ordered pair: पहले x का मान, फिर y का मान लिखा जाता है। जैसे (2, 3)।
  • Graph: दो चरों में रैखिक समीकरण का ग्राफ सामान्यतः एक सीधी रेखा होता है।
  • Solutions: ऐसी रैखिक समीकरण के सामान्यतः अनंत हल होते हैं।
Example: x + y = 5
(0,5), (1,4), (2,3), (3,2), (5,0) इसके हल हैं।

3. How to Find Solutions | हल कैसे निकालें?

उदाहरण: x + 2y = 8

  1. पहले y = 0 रखें: x = 8, इसलिए हल (8,0)।
  2. अब y = 1 रखें: x + 2 = 8, इसलिए x = 6; हल (6,1)।
  3. अब y = 2 रखें: x + 4 = 8, इसलिए x = 4; हल (4,2)।
ध्यान दें: एक समीकरण के कई हल हो सकते हैं। जाँच करने के लिए x और y के मान समीकरण में रखकर देखें।

6. Quick Revision | त्वरित दोहराव

  • सामान्य रूप: ax + by + c = 0।
  • दो चर x और y होते हैं।
  • हल को (x, y) के रूप में लिखते हैं।
  • हल जाँचने के लिए मान समीकरण में रखें।
