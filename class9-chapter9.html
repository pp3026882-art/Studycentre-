Class 9 Mathematics — Chapter 8

Exploring Sequences and Progressions

अनुक्रम और श्रेणियों की खोज

Home / होम All Chapters / सभी अध्याय ← Previous Chapter Next Chapter →

📘 Chapter Introduction | अध्याय का परिचय

English: A sequence is an ordered list of numbers that follows a particular rule or pattern. Progressions are special sequences that follow specific mathematical rules.

हिंदी: अनुक्रम संख्याओं की एक व्यवस्थित सूची है, जिसमें संख्याएँ किसी विशेष नियम या पैटर्न का पालन करती हैं। श्रेणियाँ ऐसे विशेष अनुक्रम हैं जो निश्चित गणितीय नियमों का पालन करते हैं।

Example / उदाहरण:
2, 4, 6, 8, 10, ...
प्रत्येक अगली संख्या पिछली संख्या से 2 अधिक है।

1. What Is a Sequence? | अनुक्रम क्या है?

English: A sequence is a list of numbers arranged in a definite order.

हिंदी: निश्चित क्रम में लिखी गई संख्याओं की सूची को अनुक्रम कहते हैं।

Examples | उदाहरण

  • 1, 2, 3, 4, 5, ... — counting numbers
  • 2, 4, 6, 8, 10, ... — even numbers
  • 1, 3, 5, 7, 9, ... — odd numbers
  • 5, 10, 15, 20, 25, ... — multiples of 5
  • 1, 4, 9, 16, 25, ... — square numbers

2. Terms and Positions | पद और स्थान

अनुक्रम की प्रत्येक संख्या को उसका पद (Term) कहते हैं। पद का स्थान बताता है कि वह अनुक्रम में कितने नंबर पर है।

अनुक्रम: 3, 6, 9, 12, 15, ...
पहला पद = 3
दूसरा पद = 6
तीसरा पद = 9
चौथा पद = 12
यदि अनुक्रम में nवाँ पद aₙ से दर्शाया जाए, तो a₁ पहला पद, a₂ दूसरा पद और a₃ तीसरा पद होगा।

3. Finding the Pattern | पैटर्न पहचानना

अगला पद निकालने के लिए देखिए कि संख्याओं के बीच क्या संबंध है।

Example 1: 4, 8, 12, 16, __
हर बार 4 जोड़ा गया है। अगला पद = 20
Example 2: 30, 25, 20, 15, __
हर बार 5 घटाया गया है। अगला पद = 10
Example 3: 2, 4, 8, 16, __
हर बार 2 से गुणा किया गया है। अगला पद = 32

4. Arithmetic Progression (AP) | समांतर श्रेणी

English: An arithmetic progression is a sequence in which the difference between consecutive terms remains the same.

हिंदी: जिस अनुक्रम में लगातार दो पदों का अंतर हमेशा समान रहता है, उसे समांतर श्रेणी (AP) कहते हैं।

3, 7, 11, 15, 19, ...
अंतर: 7 − 3 = 4, 11 − 7 = 4, 15 − 11 = 4
इसलिए यह AP है और सार्व अंतर 4 है।
Common Difference (d) = दूसरा पद − पहला पद
सार्व अंतर (d) = दूसरा पद − पहला पद

More examples | अन्य उदाहरण

  • 2, 5, 8, 11, ... → d = 3
  • 10, 8, 6, 4, ... → d = −2
  • 7, 7, 7, 7, ... → d = 0

5. nth Term of an AP | AP का nवाँ पद

यदि पहला पद a और सार्व अंतर d हो, तो AP का nवाँ पद निम्न सूत्र से निकाला जाता है।

aₙ = a + (n − 1)d

जहाँ:

  • a = पहला पद (First term)
  • d = सार्व अंतर (Common difference)
  • n = पद का स्थान (Position)
  • aₙ = nवाँ पद (nth term)
Solved Example:
AP: 5, 8, 11, 14, ... का 6वाँ पद निकालिए।
a = 5, d = 3, n = 6
a₆ = a + (n − 1)d
a₆ = 5 + (6 − 1) × 3
a₆ = 5 + 15 = 20

6. Sum of the First n Terms | पहले n पदों का योग

समांतर श्रेणी के पहले n पदों का योग निकालने के लिए यह सूत्र उपयोग किया जा सकता है।

Sₙ = n/2 × [2a + (n − 1)d]

यहाँ Sₙ पहले n पदों का योग, a पहला पद और d सार्व अंतर है।

Example: 2, 4, 6, 8, 10 का योग निकालिए।
n = 5, a = 2, d = 2
S₅ = 5/2 × [2(2) + (5 − 1)2]
S₅ = 5/2 × [4 + 8]
S₅ = 5/2 × 12 = 30

ध्यान दें: इन AP सूत्रों का उपयोग तभी करें जब प्रश्न में समांतर श्रेणी की शर्त पूरी होती हो।

7. Other Number Patterns | अन्य संख्या पैटर्न

Square Numbers | वर्ग संख्याएँ

1, 4, 9, 16, 25, 36, ...

nवीं वर्ग संख्या = n²

उदाहरण: पाँचवीं वर्ग संख्या = 5² = 25

Cube Numbers | घन संख्याएँ

1, 8, 27, 64, 125, ...

nवीं घन संख्या = n³

उदाहरण: तीसरी घन संख्या = 3³ = 27

8. Important Points | महत्वपूर्ण बातें

  • अनुक्रम में पद एक निश्चित क्रम में होते हैं।
  • हर अनुक्रम का नियम पहचानना आवश्यक है।
  • AP में लगातार पदों का अंतर समान होता है।
  • AP का nवाँ पद: aₙ = a + (n − 1)d
  • AP के पहले n पदों का योग: Sₙ = n/2 [2a + (n − 1)d]
  • वर्ग संख्याएँ: 1, 4, 9, 16, 25, ...
  • घन संख्याएँ: 1, 8, 27, 64, 125, ...

9. Practice Questions | अभ्यास प्रश्न

पहले स्वयं हल करने का प्रयास करें, फिर उत्तर देखें।

  1. 2, 4, 6, 8, __, __ के अगले दो पद लिखिए।
  2. 5, 10, 15, 20, __ का अगला पद लिखिए।
  3. 3, 7, 11, 15, ... का सार्व अंतर ज्ञात कीजिए।
  4. 10, 7, 4, 1, ... का सार्व अंतर ज्ञात कीजिए।
  5. 1, 4, 9, 16, __ का अगला पद लिखिए।
  6. AP: 4, 7, 10, 13, ... का 7वाँ पद निकालिए।
  7. AP: 6, 10, 14, 18, ... का 5वाँ पद निकालिए।
  8. पहले पाँच सम धनात्मक पूर्णांकों का योग निकालिए।
  9. क्या 2, 5, 8, 11, ... एक AP है? कारण बताइए।
  10. अनुक्रम 1, 2, 4, 8, 16, ... में अगला पद क्या होगा?
Answers | उत्तर:
  1. 10, 12
  2. 25
  3. d = 4
  4. d = −3
  5. 25
  6. a = 4, d = 3, n = 7; a₇ = 4 + 6 × 3 = 22
  7. a = 6, d = 4, n = 5; a₅ = 6 + 4 × 4 = 22
  8. 2 + 4 + 6 + 8 + 10 = 30
  9. हाँ, क्योंकि लगातार पदों का अंतर 3 है।
  10. 32

10. Quick Revision | त्वरित दोहराव

Sequence = व्यवस्थित पदों की सूची
AP में सार्व अंतर: d = a₂ − a₁
AP का nवाँ पद: aₙ = a + (n − 1)d
AP के पहले n पदों का योग: Sₙ = n/2 [2a + (n − 1)d]
वर्ग संख्या = n²; घन संख्या = n³

10. 15 Solved Examples | 15 हल किए गए उदाहरण

Example 1: True or False?
Statement: 5 + 3 = 8.
कथन: 5 + 3 = 8।
Answer: True / सत्य।
Example 2: True or False?
Statement: 9 is an even number.
कथन: 9 एक सम संख्या है।
Answer: False / असत्य। 9 विषम संख्या है।
Example 3: Is it a proposition?
"The Earth revolves around the Sun."
"पृथ्वी सूर्य के चारों ओर घूमती है।"
Answer: Yes, it is a true proposition.
Example 4: Is it a proposition?
"Please sit down."
"कृपया बैठ जाइए।"
Answer: No. It is a request, not a statement that is true or false.
Example 5: Identify P and Q.
If a number is divisible by 10, then it is divisible by 5.
Answer: P = divisible by 10; Q = divisible by 5. The statement is true.
Example 6: Find the converse.
If a number is divisible by 4, then it is even.
Answer: If a number is even, then it is divisible by 4. This converse is false; 6 is a counterexample.
Example 7: Find the converse.
If a shape is a square, then it has four sides.
Answer: If a shape has four sides, then it is a square. This is false because a rectangle also has four sides.
Example 8: Find the converse.
If a number is divisible by 6, then it is divisible by 3.
Answer: If a number is divisible by 3, then it is divisible by 6. This is false; 9 is a counterexample.
Example 9: Give a counterexample.
Statement: Every even number is divisible by 4.
Answer: 2 is even but is not divisible by 4.
Example 10: Give a counterexample.
Statement: Every number greater than 5 is greater than 10.
Answer: 7 is greater than 5 but not greater than 10.
Example 11: Is the statement true?
If a number is divisible by 2, then it is even.
Answer: True / सत्य.
Example 12: Is the converse true?
Original: If a number is divisible by 10, then it is divisible by 5.
Converse: If a number is divisible by 5, then it is divisible by 10.
Answer: False. 15 is divisible by 5 but not by 10.
Example 13: Find the converse.
If a triangle is equilateral, then all its sides are equal.
Answer: If all sides of a triangle are equal, then it is equilateral. This is true by the definition of an equilateral triangle.
Example 14: Identify the condition and conclusion.
If a number is a multiple of 8, then it is a multiple of 4.
Answer: Condition = multiple of 8. Conclusion = multiple of 4.
Example 15: Can a true statement have a false converse?
Answer: Yes. “If a number is divisible by 4, then it is even” is true, but its converse is false because 6 is even and not divisible by 4.
